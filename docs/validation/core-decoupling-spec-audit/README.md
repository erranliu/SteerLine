| 各 Plan 独立包测试再跑 quick 重复覆盖，零命中仍可能返回成功 | 定向用例与 quick 合成一次既有入口，逐包/命名用例核对 JSON 命中；原生单元和中心纯业务断言各有唯一所有者 |
