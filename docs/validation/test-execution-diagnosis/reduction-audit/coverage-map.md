# 重复测试工作精简审计

基线为 `543f0d4`。本轮只用临时测试 overlay 验证，未删除或修改产品工作区中的 Go 源文件。

## 可精简的固定清单

| 原位置与重复工作 | 精简方式 | 保留的覆盖 |
| --- | --- | --- |
| `TestCreateTaskBatchAtomicIdempotentAndQueryable` 为原子创建/幂等同时创建 5 个任务和菱形 DAG | 改为任务 20 → 21，加独立高优先级任务 24，共 3 个节点；删除重复的双前置阻塞断言 | 同一测试继续核对创建、同 ID 重放/异内容拒绝、固定字段 CAS、就绪优先级、分页游标失效、已丢弃 ID 不复用；双前置阻塞已有 `TestTaskGraphViewSnapshotAndBoundary` 的 3/5 → 4 场景及 list/show/graph 一致性检查 |
| `TestTaskGraphViewSnapshotAndBoundary` 在图展示断言结束后，另建两份固定契约再次完整验证环 | 删除尾部环批次准备和重复验证 | `TestTaskBatchStrictDecodeAndDeterministicCyclePath` 仍通过真实 CommandService 验环与错误码，实验额外把无副作用断言移到该测试，以前后 database/graph revision、Task/edge 数量检查；纯 taskgraph 包继续覆盖环算法 |
| `TestServiceStartControlDispatchesChosenProfile` 为测试两个 worker 的配置选择先完整执行批次创建 | 仅此用例使用测试内部的合法任务记录准备，通过原 SQLite 类型化事务写入 Batch/Task/Contract，之后全部原控制/worker/重启断言保持 | 仍经真实 start_task 控制接线、真实 worker 和中心 claim 校验；两个并行任务的 worker/profile 不串线、配置变更后重启沿用原固定值均保留；批次创建本身由核心原子/回滚/幂等及 CLI 测试负责 |

合法任务记录准备只用于上述配置选择用例，不替换 `CreateTaskBatch` 的生产实现，不用于创建命令专属测试，也不关闭 claim 时的真实契约/base/能力检查。fixture 不伪造已完成的执行或 PR 交付。

两个决策测试的创建准备也曾做同样尝试，但定向对照未显示稳定收益，最终组合实验恢复原实现，避免为不明确收益扩大改动面。

## 当前不支持整段删除的用例

| 用例/段落 | 独有或重要的被保护行为 |
| --- | --- |
| 本机完整闭环 | 真实 worker 失败后在线重试、固定 Attempt 回执、等待 PR 与完成后的重启、后继启动 |
| 本机闭环的清理段落 | 伪造清理证明拒绝、平台 PR 已关闭但数据库回执失败、重启后 PR unknown 与工作区清理独立结算、精确停止回执和观察者结束 |
| Orca 完整闭环 | UI 切换失败仍保留已创建 terminal binding；固定步骤完成到真实中心交付；后继启动回执丢失后的原 Attempt/执行槽与不重派 |
| 决策正常完成与 unknown 恢复 | 两者共用很多准备，但普通完成通知与重启对账经过不同接线；保留两条路径的应用证明与状态检查 |
| CLI 创建/补边/丢弃/导出 | 核心测试不替代 CLI 参数、退出结果和协议输出接线；保留代表性真实 CLI 用例 |

当前没有把慢用例移出默认套件、改为默认跳过或只放到人工验收中。后续若将长闭环拆为直接状态夹具，必须先迁入上述独有断言；本轮未用尚未实现的替代覆盖作为删除依据。

## 定向对照与组合实验

原型第一版对 6 个目标/存活用例做同机对照：总墙钟 110.193 → 96.342 秒，全部通过。其中原子创建 23.68 → 18.27 秒，图展示 5.42 → 1.93 秒，配置控制 29.63 → 23.36 秒。两项决策用例无稳定改善，因此最终版未保留它们的 fixture 替换。[原型补丁](prototype.patch)与[定向结果](summary.json)记录完整事实。

另一个已确认的长尾来自分组：旧哈希算法把两个最长闭环分到同一组，核心三个分组分别约 140/307/215 秒。最终组合实验使用本轮已有串行报告的顶层用例耗时作固定权重：按权重降序、名称升序排列，依次放入总权重最小的组，同权重选较小组号；新用例权重默认 1 秒、现有非正耗时下限 0.05 秒。清单仍从当前测试程序自动枚举，权重不决定是否执行，不是用例白名单。

组合实验叠加前轮已选定的只读 Git 种子及五个 DAG 反例分层，保留全部原顶层测试名称和终态检查；未纳入轻量 Git 代理。[最终实验补丁](combined-prototype.patch)与[完整运行器](run-balanced.py)用于记录这一确定组合。完整耗时与覆盖以 `../reduced-balanced-full/summary.json` 为准，不从局部节省量相加推算。
