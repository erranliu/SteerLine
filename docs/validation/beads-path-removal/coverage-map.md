# Test coverage migration map

The deleted suites exercised whole-run Beads claims, completion adapters, R-a result files and the old backend reply path. Those entry points and their fakes were removed with the production path. Native task identity, fixed-step execution, current command ownership, idempotent delivery and conservative recovery remain covered by the tests below.

The #11 crash-boundary test `TestControlCrashBoundariesNeverReplayClaimWorktreeOrWorker` covered the old multi-call Beads claim plus worktree/worker start sequence. Its native replacements check the relevant durable boundaries separately: `TestNativeClaimRechecksReadySlotAndPersistsReservationWithoutAppliedReceipt`, `TestNativeClaimCompetitionCreatesOnlyOneWorkflowReservation`, the Orca lost-start-receipt/restart case, `TestOperationIdempotencyKeepsOneDurableIntent`, and `TestSQLiteTransactionRollsBackAllDomainWrites`. The old eight-boundary count is not claimed as an identical replacement matrix.

## New refusal coverage

| Invariant | Test |
| --- | --- |
| Missing direct `Config.TaskAuthority` is rejected before state creation | `TestNewServiceRejectsNonNativeAuthorityBeforeCreatingState` |
| Retired config fields are rejected by strict JSON decoding | `TestConfigRejectsRetiredBeadsExecutionFields` |
| Old Beads task state and custom database forks are not adopted | `TestNativeInitializationRejectsBeadsStateAndCustomDatabaseFork`; `TestNativeInitializationRefusesExistingBeadsTaskDatabase` |

| Retired `accept_result` command rows block startup before mutation | `TestPreflightRejectsRetiredWholeRunResultCommandWithoutMutation` |
| Old file-based execution state is preserved and rejected | `TestPreflightRejectsRetiredFileExecutionStateWithoutMutation` |

Current-schema restart and idempotency checks are retained in `native_tasks_test.go`, `task_dag_test.go`, `sqlite_store_test.go`, and `service_lifecycle_review_test.go`. Windows live-window acceptance and live Codex/Orca/PR provider checks remain separate, opt-in gates.
