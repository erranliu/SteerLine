# 第二阶段 UI 原型

`index.html` 是可直接用浏览器打开的单文件交互原型，用于讨论页面结构、文案和状态流转。页面内的任务、回执、文档校验结果都是演示数据；按钮只切换演示状态，不连接 SteerLine 服务或 Codex。

## 如何迭代

- 小幅视觉和状态调整直接修改 `index.html`，保持无构建步骤，方便审阅 Git diff。
- 新页面或流程应同步更新 `../ui-design.md` 的产品交互和验收情景，再更新本原型。
- 当需要可复用前端组件、独立设计系统或真实 API 联调时，再把原型升级为有构建配置的 UI 工程；届时仍由 Go 服务提供业务权威接口。
- 原型稳定后，WinUI 3 实现按同一页面流程和状态语义重建原生控件，不把 HTML/WebView 当作最终 Windows UI。
