# 第二阶段产品与 UI 规划

本目录规划[产品愿景第二阶段](../roadmap/product-vision.md)：“人与主 agent 受控推进 roadmap”。这里记录产品方案、技术选择和 UI 设计；选定实施范围后，仍须按[roadmap 文档规则](../roadmap/readme.md)形成独立任务、Spec 和 Plan。本目录不代替执行 Spec，也不表示第一阶段尚在规划中的能力已经交付。

## 当前文档

- [技术架构方案](technical-architecture.md)：Windows 原生 UI、Go 服务、Codex 主 agent 的边界，以及未来各平台原生 UI 的接入方式。
- [UI 设计草案](ui-design.md)：以规划对话为中心的界面、受控文档流程、Roadmap/DAG 浏览和第一阶段 viewer 的原生替代。
- [可交互页面原型](prototype/index.html)：可直接打开和通过 Git 迭代的五页原型；演示数据和按钮不连接真实服务。

## 后续设计内容

后续继续细化页面和交互验收，并用真实 Codex App 对照输入行为，决定哪些交互能按相同语义交付。目录中的方案与草案均不代替所选任务的独立 Spec/Plan。
