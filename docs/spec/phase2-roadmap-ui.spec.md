页面保存项目、筛选、选中 ID、展开深度和阅读位置。新 SSE 事件触发查询但不强制改变选择或滚动到底；返回原页恢复位置，目标已删除/不可读保留定位诊断。过期游标刷新当前快照，不能拼接不同 graph_revision；正式文档版本变化提示旧视图并允许刷新。
