# Spec：测试耗时基线与夹具精简

任务 ID：11；任务名称：测试耗时基线与夹具精简；目标：`REFACTOR`。状态：实现与验证完成，待 PR 评审。配套 [Plan](test-feedback.plan.md)。本任务由一个独立实现 PR 交付。

## T1：目标、前置与边界

在当前代码上取得可复现的测试耗时证据，精简重复的测试准备，让后续删除旧路径和拆包有可比较的基线。无未完成任务硬前置；基于已实现的[人工决策与恢复](pr-05-intervention.spec.md)、[原生接入](beads-exit.spec.md)和[任务关系视图](dag-view.spec.md)。这些任务的真实平台验收不能由本次测试整理代替。

遵守[执行架构共同约束](execution-architecture.spec.md)与[原生任务共同约束](native-task-constraints.md)。本任务优化测试工具和夹具，不改变产品协议、业务状态机、生产超时或数据库耐久性设置。夹具指测试创建的临时仓库、数据库、模拟后端、进程和输入样例；共享可复用的不可变材料，每个用例仍有独立可写现场。

## T2：测量与可复现入口

- 提供一个小型测试入口及 JSON 日志汇总工具，支持指定 Go 包/用例；透传测试失败和退出码，保留原始输出。完整入口实际执行 `go test ./... -json -count=1 -timeout 20m`，外层记录总墙钟时间。
- 汇总包耗时、测试/子测试耗时、最慢用例、失败、跳过和未完成项。父子测试时间可能重叠，不能累加它们冒充总耗时；多个包并行时也不能把包时间之和当成墙钟时间。解析错误、进程失败、日志截断或缺少终态须显示为未完成/失败。
- 每份比较记录源码 commit 和工作树状态、命令、Go 版本、OS/架构、机器与并发设置、构建缓存条件、启用的原生验收开关。使用同一机器和相同配置比较；历史报告只作背景，不直接充当当前基线。
- 在冻结源码上记录一次修改前和一次最终完整运行。只对候选慢用例组做至少三次前后配对测量并比较中位数，不要求重复运行三遍整个二十分钟套件。预编译/构建成本与实际测试成本分别报告，不把预热收益算作业务代码加速。
- 真实 GitHub/Orca、可见 Windows 服务窗口等已有显式开启的原生验收保持单独列示，未运行不能算通过。默认确定性套件中的测试不移入默认跳过的标签或环境开关。

## T3：夹具精简与覆盖去重

依据当前逐用例报告选择实际耗时最高且可改善的夹具组。优先消除重复 CLI 构建、与断言无关的 Git/worker 准备和固定等待；纯校验用例使用最小输入，进程交互用事件或可观测条件同步并保留有界超时。

共享构建产物限本次测试运行且必须对应当前源码；可复用只读种子，但仓库、数据库、端口、工作区和模拟平台可写状态按用例隔离，不能共享运行中的服务。保留原有真实子进程、Git、SQLite 崩溃/并发测试中与其断言相关的现场。不得以模拟取代这些行为本身的验收。

对删除、合并或降层的测试建立“原用例 → 受保护行为 → 新用例/仍有覆盖的用例”映射；仅历史路径专属行为留给 #12 删除。本次至少有一组测得的慢夹具减少可数的准备动作，且其配对运行中位数下降；记录端到端影响。没有实际改善不能仅凭新增计时脚本宣告完成。完整套件若变慢，必须分析来源并消除改动引入的回归，不能扩大时限掩盖。

## T4：运行与交接

交付测试使用文档：日常运行受影响的包和必要的跨模块用例；稳定候选版本在合入前运行一次完整无缓存回归。后续修改仍须重跑受影响验证；只有新变更、失败或未解决风险才扩大重测。依赖外部进程/平台事实的用例显式无缓存运行；快速纯规则测试可使用 Go 正常缓存。

向 [#12](beads-path-removal.spec.md) 交接慢用例列表、夹具用途与覆盖映射，向 [#13](taskgraph-modules.spec.md) 交接相同测量格式及按模块反馈基线。实现期间与 #3 的同一原生验收资源互斥；与 #6 涉及相同 fixture 的修改串行集成。
