# 第一阶段交付共同约束

本文约束持续 worker/候选基线、#83 的安装/调试路径隔离与[一期验收活动](../acceptance/phase1.md)的单安装版阶段签收。#40/#41 完整版本管理延后，保留草案但不作为当前执行入口。每项启用任务各有独立 Spec/Plan 与一个实现 PR；本文不代替执行任务。

## 当前平台范围

第一阶段包含本地 Codex、本机 Orca 与远端路径交付。远端路径按[专属 Spec](orca-remote-l3.spec.md)与[验收记录](../acceptance/orca-remote-l3.md)核对实际能力和结果。

## 权威与执行边界

当前基线已具备持续worker、固定身份/权限、原请求对账、服务独立生命周期及规范事件/正文。后续直接保持这些边界，不把已交付Spec作为通用追读前置。SQLite是Task、执行、反馈和TaskDelivery的唯一权威，UI、启动脚本和候选汇总不复制业务状态。规划文件修订不改写中心冻结契约；执行前核对实际 Task commit/摘要/依赖，旧范围按受控替换及消费者身份同步处理。

worker 依据任务 Spec/Plan 实现、提交和创建 PR。测试、修复、审查及文件提交要求来自该任务契约；中心不维护五步、验证/审查结果链、修复轮数或工作树 dirty 门槛。

发布责任仅worker，中心不commit/push/create，也不接受host_service或方案委托发布。原生能力逐执行目标核验，不能以中心权限或兄弟成功代替。产品活动/会话/正文/raw只读数据库已提交规范记录，诊断日志不是自动回退来源。

环境blocker独立于agent业务Decision，阻断时拒绝新反馈、不队列补投；环境动作绑定原Execution/Attempt/turn/blocker与服务实例。生命周期副作用复用唯一actor的后台单步通道，原intent/receipt/ack提交屏障保持；候选新增/放弃不另建引擎或等待停止的项目级槽位。

#37 明确扩展 #36 的单候选边界：稳定任务可人工增加不同执行配置的候选，每个WorkflowRun保持自己的原worker会话。开始时观察参与数已达5个就拒绝，不建立严格名额、队列或停止确认门槛；并发请求偶尔超出可接受。PR合并前可放弃单个候选，退出实验立即生效，停止与资源事实另行记录；已知PR合并后不允许放弃。一个Task只记录一个真实PR核验过的Delivery，人完成实验比较和合并选择，中心不自动评分/融合，不把放弃或落选等同于停止。一期外部提供稳定roadmap；主agent、审核及正式准入归二期。

## 操作与持久化

新的开始、反馈或候选操作保存固定意图后再执行外部调用；回执和消息持久化后推进游标。相同请求重交复用原记录，未知外部动作先对账，不能改 ID 盲重发。主状态表达用户进度，传输/资源错误是事实，不衍生项目专用恢复状态机。当前不增加版本选择操作。

PR 真实存在、归属和实际合并由 provider 核验；唯一交付、Task.closed 和后继资格同一事务提交。任务丢弃沿现有未合并核验和资源保留规则，不把用户任意反馈当成直接修改中心状态。

## 格式与版本隔离

本组以 #36 实际发布的持续会话协议为基础。默认不兼容旧开发配置、数据库或执行记录，不保留旧 schema 5/legacy 摘要双模式；若独立任务要求跨格式保留，必须另行明确输入范围和受控转换。当前格式内的 Task/会话/消息/PR 重启恢复及原操作对账必须通过。

不支持的格式在外部副作用前拒绝，原库和外部绑定保留供人工核实，不清库升级、不恢复旧快照掩盖副作用。安装版与源码调试使用不同 exe/home 和测试 clone，配置、SQLite、日志、服务文件及工作区不共享。显式 run_dir/worktree_root 也受调试路径约束；同仓库跨 home 的单写锁继续生效，linked worktree 不视为独立 clone。

安装验收构建保持干净 commit 与固定 SHA-256，调试允许 dirty 但准确显示来源；这与目标项目文件改动分别处理。worker 如何处理 `.meta` 等文件不由运行入口决定。日常 build 不覆盖安装 exe；人工更新先核实并结算外部执行，再停中心、替换和启动，不承诺跨构建接管活动状态。停止中心监督不等于停止外部 worker。

#40/#41 重新启用时另行固定版本管理与提升范围；当前 #83 隔离和 一期活动的同构建重启证据不能充当版本选择/提升证明。

## 验证

各任务按最小必要范围选择受影响Go/事务/接线用例与一次L1，使用[测试总入口](../testing.md)和[E2E约定](../../tests/e2e/README.md)。修改Plan必须列测试级别、组/场景ID、环境、命令、时点、通过条件和证据；迁移测试核验实际命中。纯规划不运行产品测试。仅有新增失败或未覆盖风险时扩大验证，Full按现有并行入口显式选择，不默认运行。跨OS源码/依赖检查保持Windows/Linux代表；原生证据只重验受影响增量。#83验最小 controlled 共存，一期活动验精确安装产物上的双本机链/同构建重启/24小时，二期活动验完整产品链。已有 L2/L3 按实际构建和接线影响复用，不把短时 E2E 当作长期稳定证明，不扩大为全排列矩阵。

真机使用隔离项目和当前已认证目标；模拟或编译通过不等于平台通过。测试 PR 由操作者合并，系统只核验；本机停止支持/不支持/待核实按实际能力展示。所有自动/人工验收行为与状态集中于[acceptance](../acceptance/README.md)，原始证据留临时目录。纯文档修改检查身份、依赖、链接和语义，不运行实现验收。
