# Spec：WinUI 基座与原生输入

任务 ID：44；任务名称：WinUI 基座与原生输入；目标：`PHASE2`。状态：规格已编写，尚未实现或验收。配套 [Plan](phase2-winui-foundation.plan.md)。本任务由一个独立实现 PR 交付。

## 范围与前置

硬前置：无。
遵守[第二阶段共同约束](phase2-constraints.md)。新增 Windows C# / WinUI 3 客户端基座，交付可复现构建入口与真实原生窗口。只包含项目/session 导航骨架、原生输入、公共状态区和页面容器；领域页面由各自任务交付。

## 界面契约

主窗口以规划对话为默认入口，左侧项目/session 与规划、Roadmap、DAG、执行导航；右侧上下文区域可折叠，窄窗口使用抽屉，输入区和待处理提示保持可达。对外提供按 project_id、session_id、task_id、execution_id、proposal_id 打开的导航数据结构；未知对象保留定位信息并显示不可用，不猜测相似标题。

采用原生多行文本编辑：中文 IME 组词时 Enter 只提交组词；默认 Enter 发送、Shift+Enter 换行，可在本地设置选择 Ctrl+Enter 发送。发送前后保留选区/撤销的合理语义，支持大段多行粘贴、键盘焦点和屏幕阅读器标签。未发送文本按项目/session 隔离保存，切换和进程重开恢复；新 session 不能继承旧输入草稿。发送只产生 UI 意图，由后来接入的客户端负责真实提交。

提供共同连接状态模型：未启动、连接中、在线、离线、身份不匹配、存活未知；基座样例明确标为演示，不伪造真实任务成功。会话页局部禁用不得锁死导航或历史阅读。项目切换不能把旧请求回执投到新项目。

## 生命周期与构建

UI 不启动/停止 Go 服务，也不携带嵌入式任务状态机。关闭窗口仅保存本地视图，服务进程不由窗口拥有。给出 Windows 原生构建/运行命令，固定 .NET/Windows App SDK 依赖与最低可验证系统版本；本任务包含开发运行所需配置，不承担正式安装升级方案。README 与应用内不宣称 macOS/Linux 已支持。
