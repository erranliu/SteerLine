## 客户端边界

TUI 的业务消费路径不得打开 SQLite、读取运行 checkpoint/宿主业务命令与回执文件、解析私有日志、调用执行/工作区/PR adapter 或构造本地产品业务适配器。所需业务只能经 HTTP；服务端仍可组装既有内部产品适配器。

允许客户端读取自己的连接配置、受限 discovery/credential，保存偏好、未发送草稿和完整原请求；这些文件不是业务权威。加载项目连接不得初始化业务库或取得业务写锁。客户端格式/显示可用性检查不替代服务资格核验。

当前 httpapi 包同时包含客户端与服务端，直接引用它不能证明解耦。实施中分开必要的纯 HTTP 信封/DTO/codec、客户端和服务端 handler 所有者；对 TUI 实际组装入口及客户端直接/传递依赖检查，拒绝 SQL、后端业务和 handler。共用 CLI 可继续同一 exe；整个 cmd/steerline 的后端闭包不作客户端隔离判据，不要求拆独立 exe。

## 能力映射

| 现有能力 | HTTP 接入安排 |
| --- | --- |
| 多项目、任务/候选/方案/状态、直接关系和阻塞 | 复用 identity/snapshot/tasks/runs/presentation；方案发送 ID，由服务核验冻结配置/digest |
| 近期活动、当前/历史 final、背景与历史决策 | 复用 activity/conversation/body/snapshot，保留身份、分页、revision/摘要、大小边界和缺口 |
| 开始/新增/放弃、派发、文字/选项/备注、环境动作 | 公共命令信封映射原入口，所有等待/读取绑定原 request ID，不绕过目标版本 |
| `u` 恢复核验 | 补公开只读查询，绑定 run/Execution/Attempt，返回原结论、采样和缺口，不授予资格 |
| Ctrl+N 原会话查看 | 补类型化命令，绑定 run/Execution/Attempt/session/generation，服务沿冻结路径核验并打开原 Codex/Orca 目标；与阻断 open_terminal 分开，不创建业务轮次 |
| 服务停止、窗口关闭与重连 | 公开原 stop 回执和准确结果，关闭窗口只结束客户端；重连保留原身份和请求 |

路由/DTO/action 表由本任务同步到[客户端协议](../product-design/local-client-protocol.md)。缺失恢复/原会话接口不得静默降级为 unsupported；平台本来不支持的能力继续显示真实原因，不扩大支持声明。

## 原请求、停服和离线

发送前保存完整原信封；同 ID/内容返回原记录，异内容拒绝。丢回执先查原 ID，只有同项目权威明确 command_not_found 才按原 ID/内容/版本补交。旧实例、未知外部结果不自动重发。保存、接受、应用、新轮次和交付分别显示；项目切换、旧响应、失效游标不混用目标。

停服业务回执只从 HTTP 取得，不能从 inbox/回执文件补读。服务退出前提供可取得的持久处理回执，客户端保存已取得的原记录。本机连接生命周期适配层可按经 HTTP 认证的精确进程身份核验 OS 退出/原锁释放，不读取业务状态或补造 applied；缺少原 applied 或退出/锁证据时明确“结果未核实”。断线不代表成功，不启动备用查询服务；正常停服和丢回执必须分别验证。

服务离线保留已观察内容、采样和未发送输入，禁止业务变更；重开无已有观察时显示不可查询原因。停服后历史不再通过 TUI 直接读库，这一行为变化须更新帮助和产品说明，不建离线查询进程。

## 远程预留与验收

连接分开表达地址、项目/实例与执行目标，路径属于服务/执行机器。本机发现/生命周期观察不写入通用业务资格规则；当前仅接受本机连接，不新增远程开关、监听、认证、多用户或部署成功声明。

| ID | 最小通过条件 |
| --- | --- |
| TH-A1 | 实际 TUI 客户端组装/消费仅经 HTTP，直接/传递依赖及文件访问守卫通过，无业务库或文件传输回退 |
| TH-A2 | 查询内容、身份、正文/分页/缺口与服务一致，错项目、旧响应和失效游标不串线 |
| TH-A3 | 原开始/新增/放弃/派发/反馈/环境命令到原目标，重复/丢回执/旧版本/重开恢复，副作用至多一次 |
| TH-A4 | 恢复核验和原会话查看保持原语义；错绑定拒绝，核验只读，查看不创建业务轮次 |
| TH-A5 | 停服正常与丢回执有证据结果或明确未核实；窗口关闭后服务/worker继续，离线禁写、重连不重放 |
| TH-A6 | #44 工程/专属配置/入口删除，原 Go 构建和身份/导航通过，历史失败/未验不重标通过 |
| TH-M1 | Windows 真终端中原键位、中文多行、候选/final/原会话入口可用，无误提交；人工窗口待安排，允许自动通过后集中到任务签收前 |

行为/实际结果只登记专属 acceptance，Plan 不维护实时状态；必要回归不替代产品验收。现有平台限制不因传输改造被豁免。
