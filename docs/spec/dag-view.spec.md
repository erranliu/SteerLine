# Spec：任务关系视图与 JSON 导出

任务 ID：10；任务名称：任务关系视图；目标：`DAG-VIEW`。状态：待实施。配套 [Plan](dag-view.plan.md)。本任务由一个独立实现 PR 交付。

## V1：范围与前置

前置：[原生接入 Spec](beads-exit.spec.md)、[固定 DAG Spec](task-dag.spec.md) 的关系查询和[控制台 Spec](pr-04-console.spec.md)的查询边界已交付。复用[原生任务共同约束](native-task-constraints.md)和[原生任务模型](task-core.spec.md)的版本规则。

本任务只交付控制台中的任务上下游、阻塞详情和只读 JSON 导出。中心查询仍是任务与就绪状态的唯一权威；本任务不创建、丢弃或修改任务，不提供 DOT/SVG 渲染或交互式图编辑。

## V2：查询与导出

`native-task-graph/v1` 从同一数据库读取快照返回节点、前置边、采样版本、过滤条件和未展示的边界。节点包含稳定 task_id、标题、状态和阻塞原因；被丢弃的前置及其后继阻塞仍可见。图查询支持项目、状态和以 task_id 为中心的上游/下游筛选，默认深度 1，最大深度 10；单次最多返回 500 个节点。结果截断时标明边界，不显示成完整图。

控制台通过 QueryService 展示选中任务的前置、后继、阻塞、规格和交付定位，刷新后按 task_id 保留选择。离线数据标明采样时间，不把旧 ready 当作启动许可。

`task export -format json -output <path>` 导出同一查询快照，JSON 不能作为 task-batch/v1 再次创建任务。完整导出超过节点上限返回 export_limit_exceeded；筛选导出保留边界与采样版本。文件在同目录原子发布，已有文件须显式允许覆盖；导出失败不影响调度或现有文件。
