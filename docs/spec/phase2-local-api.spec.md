# Spec：本机客户端协议与历史查询

任务 ID：45；任务名称：本机客户端协议与历史查询；目标：`PHASE2.1`。状态：已纳入执行规划、待中心准入及实现/验收，一个独立实现 PR。配套 [Plan](phase2-local-api.plan.md)及[验收](../acceptance/phase2-local-api.md)。本次只修订草稿，不改变外部已固定契约。

## 范围与前置

无未完成硬前置；复用已交付持续 worker、双本机多候选及现有产品 Query/Command。遵守[二期共同约束](phase2-constraints.md)。交付原生客户端确定会使用的执行传输；历史查询指现有服务可提供的任务、决策和最终回复，不包含新增离线查询进程。

输入/输出以 internal/product/api、client、query 为基线，HTTP 只做适配。任务、候选、Execution、Attempt、Decision、原请求及服务实例身份不得折叠成一个“当前任务”。不新增执行状态机、全仓结构整理、规划领域 DTO 或通用 artifact 框架。

## 连接与认证

服务取得现有项目锁并完成恢复后，在 127.0.0.1 随机端口开放 HTTP。发现文件记录协议、项目/实例、进程身份、地址及凭证文件位置；每实例随机凭证位于当前用户受限目录，Windows ACL 核验当前用户读取范围。Authorization 请求头传凭证，不进入 URL 或日志。拒绝错误 Host、浏览器 Origin、非回环请求和错误凭证，不启用任意 CORS。

GET /v1/identity 校验项目、实例、协议和能力。旧发现文件、ready=false、权限不足和端口冲突给出明确原因；客户端不据超时另起服务。传输随原服务退出，UI 关闭不停止服务。路径由现有宿主显式传递，后续 #83 改动时核对接线，不把共享修改顺序当作业务硬依赖。

## 查询与命令

项目路由以 /v1/projects/{project_id} 为根。提供任务列表/详情、候选和执行详情、基本有界 DAG、近期活动、完整最终回复、问题/历史决策、PR/交付、连接及阻塞原因查询。直接前置/后继和有界图分页复用现有能力；不恢复已退役的高级邻域组合或完整过程阅读器。

POST /commands 映射现有控制台的首候选/新增候选、方案选择、候选放弃、Task 丢弃、原问题文字/选项/备注反馈、派发控制、服务停止与已有环境核验动作。只有已有真实能力可以装配；未知领域或动作返回 unsupported。实现交付机器可读 action/DTO 映射和代表性契约样例，不提前编造规划、人工验收或前置操作领域的 handler。

命令绑定原项目、目标、expected_version 和 request_id；服务重检资格。原请求重复同内容返回原记录，异内容拒绝。GET /commands/{request_id} 仅在权威确无记录时返回 command_not_found，离线/查库失败/身份错误不能伪装成不存在。补交只能用同一原信封且先完成持久唯一仲裁；已登记的未知外部动作只对账，不重复调用后端。

查询返回实际对象/快照版本和采样时间；分页失效刷新，不拼接不同版本。业务回执和正文由现有持久查询取得，不把通知或 UI 缓存当权威。

## 交付与延期范围

首版用查询刷新与原请求回读即可闭环。本任务不要求 SSE 或持久通知游标；若后续真实页面确认需要，再按实际消费范围扩展，不先建通知平台。完整离线历史、新 CLI JSON 查询入口、规划文档发布、草稿/通用 artifact 模型、人工后验收和自定义前置操作流程均延期。

交接包含协议身份、路由、DTO/action 表、错误与分页样例、真实 Windows 连接命令及原请求对账说明，供 #44/#49/#50 消费。
