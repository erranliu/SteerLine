# Spec：任务应用用例归包

任务 ID：75；任务名称：任务应用用例归包；目标：`TASK-EXECUTION-CONSOLE-DECOUPLING`。配套 [Plan](three-line-03-task-usecases.plan.md)。一个独立实现 PR 交付。

## 范围与前置

硬前置：#74。把任务创建/固定契约、批次、依赖、资格/挑选、丢弃意图及规范化结果应用迁到 `internal/task`，切换 CLI/服务调用并删除对应主包用例。

实际盘点起点：主包 `native_batch_command.go`、`native_contract_files.go`、`native_task_predecessors.go`、`native_discard_command.go`、`native_delivery_command.go` 中任务职责，相关文档读取与配置输入；按 #74 清单拆函数，不整文件搬走执行职责。开工时按实际消费者核对路径；前置迁移已发生的部分只承接其唯一实现，不重建。

## 实现要求

1. 任务应用只依赖 task/model、自有小端口和必需 storage/ports，不导入 execution model/backend/adapter、具体 SQLite、product 实现、app 或 UI。工作选择和结果应用继续用 #74 唯一规则。

2. 注入固定文档读取端口与项目/文档根/提交标识等最小输入；不把完整 Config、连接工厂、Service 或 Runtime 传给任务。读取、digest、路径校验和创建回执的既有行为保持。

3. 任务记录丢弃意图、合法状态及 DAG 资格；执行核验/停止/清理由注入边界处理，任务不得查询 provider 或进程。固定身份、前值、版本、幂等、结果去重保留。

4. 真实批次创建、追加前置、服务挑选与执行结果应用立即改为调用 task 用例；app 本阶段完成局部构造，不能把接线修复留到 #80。与 #76 共享协调文件遵循 #74 唯一所有者清单。

## 共同执行约束

遵守 [三线解耦共同实现约束](three-line-constraints.spec.md) 的最终依赖矩阵与跨域提交规则；本阶段负责实际启用自己迁移部分的守卫。

保持当前任务/DAG、持续 worker、人工并行/自动派发、原会话反馈、恢复授权、唯一交付和 UI 生命周期。失败、轮次结束、最终回复、交付、任务关闭与资源停止分别表达。具体实现无业务写权，状态仍由唯一业务写者经窄声明提交；同数据库查询保持同读快照。

同仓库、同 go.mod、同 SQLite 和服务部署方式；不引入新进程协议、后端、严格候选名额、评分/融合或规划实现。纯结构迁移保持数据格式；确需调整格式时由唯一所有者统一支持版本与拒绝边界，不新增旧版读取、迁移、双写或回退。各步切换真实消费者/构造/测试并当场删除迁出定义，保持可构建，不留永久兼容门面。

完整实施须硬前置整体交付；只读盘点可提前。共享定义、Service/Config/组装/runner 段先确定一个修改所有者并顺序集成，禁止多条线独立重写共同文件。与 #38/#39 并行使用隔离 worktree/构建/配置/测试资源；#39 记录固定构建，不在运行中替换现场。迁移后按实际接线/行为影响决定证据复用或定向重验，零命中、skip 或 mock 都不能代表本机原生通过；远端流程不纳入一期验收。
