## 目标与共同边界

保留三窗并收窄职责：左侧任务列表、右上只读候选概要、右下运行与反馈。删除完整过程阅读器及阅读偏好持久化；保留布局不等于恢复旧时间线。覆盖已接受的取舍 1、2、7。

本系列完整保留多后端、远端协议与执行路径、多候选人工实验、不同任务的人工并行、原会话反馈、当前格式恢复和真实唯一 PR 交付。各候选继续独立冻结执行配置、共同 base、工作区、session、问题与请求身份。自动派发仅开始首候选、开始时五个参与候选检查及既有资格规则不变。不因精简新增评分、融合、严格名额或实验调度器。

SQLite 继续是业务唯一权威，唯一 execution actor 通过原 intent → Execute/Reconcile → receipt → 下一步/ack 通道执行副作用。未知结果沿原请求只读对账，不重发、不创建替代会话。交付仍核验包括放弃、落选和历史候选在内的已知 PR 集合；仅一次 TaskDelivery 和后继解锁。

多后端及远端是本系列保留的核心范围；现有远端权限证据缺口仍按实际原因拒绝，不删除远端实现，也不把本机验收或配置精简当成远端可运行证明。本系列不补建新的远端平台能力。

本 Spec 替代 [候选控制台](../archive/spec/completed/candidate-console.spec.md)及既有会话展示规格中完整过程阅读、阅读锚点/折叠持久化和独立面板的要求；原候选身份、反馈、原始内容、缺口和回执边界继续成立。后两批引用上述共同边界。历史 Spec 不回写；未来规划会话 UI 不因此取消。

## 产品行为

1. 主界面保留项目选择及三窗。左侧是 Task 列表，每 Task 一条主行；右上是所选候选、冻结方案、执行/业务状态、独立环境阻断、PR、耗时及采样信息；右下是运行与反馈区。沿用稳定 P1/P2 编号和精确 WorkflowRun ID选择当前/历史候选，刷新、重排及迟到响应不改变目标。候选退出或任务完成不等同于 worker 停止。
2. 右下按三种状态显示：没有待回答问题时，显示当前运行状态、最近最多10条已提交规范活动摘要及最后采样时间；有待回答问题时，优先显示原问题、声明选项及按 a 激活的内嵌文字输入；答案已提交时，显示答案预览和保存/送达/新轮次回执，随后继续显示运行动态。状态以数据库事实为准，不从终端文字猜测活动。活动只显示短标题/状态/必要短说明，不展开工具正文、完整meta或全文过程。
3. 右下只保留有界摘要缓冲和简单滚动，不提供历史活动翻页、过程正文展开、折叠或阅读锚点；项目/候选/Execution/当前Attempt变化时清空缓冲并拒绝旧响应。采集错误/缺口明确显示，不从日志回填。完整身份、资源定位、问题背景/选项详情、历史决策及只读核验仍通过简单详情阅读入口查看。基本任务前置/后继和阻塞可查看；第三批再收窄高级图查询。
4. 保留方案选择后开始首候选/新增候选、放弃所选候选、反馈、派发控制及服务停止。服务重检原身份、版本、资格和配置，UI不是授权。环境重查和原终端动作仍绑定原blocker/turn/instance；没有能力显示原因，不承诺所有后端通用打开会话。
5. 按 a 在右下激活既有编辑逻辑，复用同一Unicode多行、选项、草稿及提交实现，不建第二编辑器，不因普通回答切换整页详情。Tab/Shift+Tab循环左侧列表、右下选项、输入；没有选项时跳过选项焦点，没有编辑时切换列表/右下滚动焦点。输入焦点Enter换行；选项焦点Enter仅转输入；F2是唯一答案提交。普通视图Enter只读详情或激活原问题，方案选择页Enter仍明确确认开始。F8按需阅读完整背景/身份，返回仍是原候选草稿。
6. 编辑中可在列表焦点选择任务，或用F6/F7切候选；先保存草稿并关闭原编辑，不把输入带到新目标。问题或实例/版本变化保留原草稿但F2拒绝，不自动重新绑定或采用新版本补投。原问题已解决或候选退出时停止原编辑，重新按a只打开当前问题。提交后留在右下答案预览/回执；未知只查原请求，拒绝恢复同一草稿，环境阻断保留编辑但禁止提交。
7. 右下不承担完整阅读器；每个候选仍可按f在简单只读入口查看已采集完整最终回复，默认最新已确认业务轮次，[ / ]选择历史最终回复。准备轮、过程和未知阶段不冒充final；缺口明确显示。正文沿用大小上限/有界读取及简单滚动，不恢复跨重启阅读位置，不用摘要冒充完整正文。
8. 删除完整transcript时间线、工具过程正文阅读、轮次折叠/保持展开和过程正文/会话历史翻页。原生会话/诊断仅提供已有可核实定位，没有打开入口如实说明。诊断由用户手动查看，不新增全量transcript导出器，不从raw日志自动补画。
9. 重开采用默认布局，不保存焦点、滚动、面板、折叠、正文offset/pages、活动缓冲或历史attempt阅读选择。窄屏不足时列表与右侧区域按焦点切换；编辑仍在主界面右侧，不切成第二套整页编辑器；高度不足时右侧优先留给问题、输入与预览。窄屏列表焦点下F2只返回原草稿预览，再次显式F2才提交，不能发送不可见编辑内容。保留可见输入焦点、预览与F2/Esc提示；长问题/选项通过F8完整读取。重开默认选择不改变持久请求或草稿目标。

## 最小持久化与删除范围

现有视图文件混有操作日志和草稿，不能整套删除。缩减现有存储，仅保留按项目/Task/候选/Decision 身份绑定的答案草稿与操作对账所需字段。原 request/command ID、动作、目标/实例/版本、冻结方案摘要和核对请求内容所需 payload 在外发前保存；保存失败不发送。重开只查原请求，不自动补投未确认输入。已终态操作按现有有界保留策略处理，不保存完整回执诊断正文作为权威。

保留必要文件原子写和多窗口隔离/锁，不另建 UI 数据库、通用偏好系统或新的命令队列。草稿不承担自动发送职责；新 Decision 不继承旧答案。读取损坏的操作记录不能猜测未发送并生成新 ID；保留现场并说明对账缺口，基本只读查看仍可用。

重点修改 `internal/console` 的导航、渲染、conversation/anchor、preferences 和候选反馈接线，收窄 `internal/product/api`、`query`、`client` 中仅供退役页面的读取契约。最终正文、问题、事件采集/去重、原生结算/恢复和诊断证据仍有消费者的部分保留。删除退役方法、字段、快捷键、说明和专属测试，不留转发、空实现或自动 raw fallback；共享断言留在必要路径。

持久结构/公开协议确需变更时，在实施 Plan 固定受影响版本并严格拒绝旧开发格式；不迁移、双写或回退。视图偏好消失不删除中心业务记录。更新 README 与会话/活动操作文档。
