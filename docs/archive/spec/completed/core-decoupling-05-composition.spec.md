# Spec 内置实现组装与主包依赖反转

任务 ID：66；任务名称：内置实现组装与主包依赖反转；目标：`CORE-IMPLEMENTATION-DECOUPLING`。配套 [Plan](core-decoupling-05-composition.plan.md)。硬前置：#65 整体交付，一个实现 PR 完成。

## 目标与范围

将所有内置实现目录、具体工厂及实现配置/codec/能力注册移到外层应用组装。主包依赖注入通用能力，任何生产入口都不通过隐藏默认实现启动。

遵守[共同约束](core-decoupling-constraints.md)，承接当前执行隔离及恢复修复，不回写历史 Spec。迁移输入：`execution_registry.go`、Config/Profile 工厂与静态判断、backend/capability/snapshot 组装、NewService/Claim/Query/console 构造和 cmd/steerline/cmd/test-feedback 入口。承接 #62–#65 通用端口。

## 构造链与依赖注入

| 方向/所有者 | 输入或输出 | 固定语义 |
| --- | --- | --- |
| cmd → steerlineapp | 应用构造 | 读取具体配置，构造不可变目录和实际依赖，向主包服务/命令/查询构造传入必要端口。 |
| steerlineapp → 实现包 | 固定实现配置 | 仅构造/校验所需值及操作依赖；业务写者、整份 Domain 和可写 Runtime 不传入。 |
| steerlineapp → steerline | 明确依赖值 | 实现目录、codec/能力、生命周期、采集和宿主端口；不能包含由主包反向选择的默认实现。 |
| cmd/外层 → 查询/控制台 | 读取和配置选择 | 复用既有 Query/Command 与同一次投影，依赖公共摘要及固定 digest；入口在外层创建目录/查询来源并注入控制台；控制台不反向导入 steerlineapp（应用组装可依赖控制台），避免目录与 UI 的依赖环。具体实现组装不成为第二套 UI 状态机。 |

## 必须交付的契约与消费者

1. 新外层应用组装包为 internal/steerlineapp，与主包并列。它导入 steerline 与具体实现，构建不可变、显式版本化的内置目录；平台工厂/codec/原生默认值在此注册，不放回 root init 或全局可变 registry。

2. 主包对目录只操作通用实现 key/版本和能力，不硬编码 host/agent/协议字符串。配置受理、候选可用性、静态支持、Claim、两阶段冻结、资源恢复、历史采集、宿主动作和查询展示使用同一个注入目录；不同快照须按原 key/版本核验，不按当前默认选项恢复。

3. Config 的业务值仍由中心使用；具体配置读取/字段解码/规范化属于外层及其 codec。CLI/console 接收配置数据并交受理接口，展示使用非秘密公共摘要，不能改为在 UI 中解释 Windows/native 参数。需要外移 Config loader 和旧 Config 方法的实际消费者一并迁移。

4. 所有产品入口使用外层应用构造：新服务、重启服务、任务命令/Claim、能力查询、项目只读查询、控制台、独立进程及测试工具。NewService/命令服务等核心构造显式要求端口；缺目录、缺 key/版本/必需能力，在操作该目标的外部调用和数据库变更前拒绝；其他完整路径的只读离线查询不要求启动能力或目标在线，仍可读持久事实、显示未知/缺失支持并禁止 mutation。不得保留 root NewServiceWithDefault 或等效兼容转发。

5. 具体 platform/process helper 若参与启动构造，归适配器或外层进程实现并通过小端口注入；中心服务自己的单写者、同步/后台消息、业务状态和 SQLite 连接所有权不外移到该组装包。只允许构造所需端口，不导出任意 mutable Domain 或仅供 test 修改的字段。

## 删除与剩余所有者

移除 root 内置注册、具体工厂、配置平台 key 字面量、权限/版本/能力组装和所有平台 import；已阶段迁移的空 shim/别名删除。root 生产文件名及源码 codex/orca 命中在本轮达到零，不能把生产清零遗留给 #67。既有 CLI 调用都迁到唯一外层入口。任何因构造 API 改变而不能编译的测试本轮就迁移或改用中性依赖，不能留到 #67；root 同包测试不得导入反向依赖 root 的 steerlineapp。#67 只归位仍能独立编译的具体协议/fixture 测试及最终守卫。

只完成目前实现的构造，不增加动态插件发现或配置热装载；不扩大 remote 能力。本轮根包生产隔离交付，#67 只移动尚存平台测试及最终自动守卫。

## 开工与集成

#65 整体交付后才完整开工。准备性阅读不构成提前领取资格。共享 execution/contracts、主包配置/Service/事务接线及原生 fixture 的变更串行处理；本任务当场删除已切换消费者的原实现，不交付双路或空接口。
