# Plan：任务关系视图与 JSON 导出

任务 ID：10；任务名称：任务关系视图；目标：`DAG-VIEW`。唯一执行依据：[Spec](dag-view.spec.md)，共同要求见[原生任务共同约束](../../../spec/native-task-constraints.md)。前置为原生接入、固定 DAG 关系查询和控制台查询边界。本任务由一个独立实现 PR 交付。

## 实施步骤

1. 复用中心任务关系 DTO，在同一读取快照中按项目、状态和任务邻域筛选节点与边；实现深度、数量、边界和游标失效规则，不重算 ready。
2. 控制台通过 QueryService 展示前置、后继、阻塞、规格与交付详情；按 task_id 保留选择，离线数据标明采样时间。
3. 实现 JSON 导出，保留过滤条件、边界和采样版本。输出原子写入，文件已存在时要求显式覆盖；失败不改业务状态。
4. 用 10/100/500 节点、循环被前置拒绝后的图、分支汇合、丢弃前置、中文长标题和恶意文本样本验证 NT18–NT20、NT21-VIEW。记录查询耗时、输出摘要和实际结果，运行针对性 Go 测试、完整 Go 测试、静态检查及 `git diff --check`。

证据保存到 `docs/validation/dag-view/`。未运行项不得记为通过；本任务不增加图渲染器、Web 服务或第二任务权威。
