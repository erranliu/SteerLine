# Roadmap 规划与执行入口

每次设计或修改 roadmap，先读 [RoadmapGuide](RoadmapGuide.md)，再按其索引读取必要文档。

草稿位于 drafts/，可按本轮目标选定、新建或修改，不在此逐份维护清单。日常执行只读取用户确认的[正式执行清单](execution-map.md)，不从草稿、文件编号或旧运行队列派发。

开发规划的任务与依赖以 execution-map 为权威，草稿和编号不产生执行授权，也不办理外部中心准入。SteerLine 产品自身的 Task/DAG 规则与仓库开发调度分别核对，见 RoadmapGuide。

编号、Spec/Plan、准入、同步和维护规则由 RoadmapGuide 统一维护。本页只提供入口，不复制规则或索引具体草稿。
