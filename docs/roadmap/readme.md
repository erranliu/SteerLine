# Roadmap 规划与执行入口

每次设计或修改 roadmap，先读 [RoadmapGuide](RoadmapGuide.md)，再按其索引读取必要文档。

草稿位于 drafts/，可按本轮目标选定、新建或修改，不在此逐份维护清单。日常执行只读取与中心 Task DAG 同步的[正式执行清单](execution-map.md)，不从草稿、文件编号或旧运行队列派发。

Task/DAG 由外部工具 SteerLine 管理；仓库执行清单仅映射其实际结果，文件编辑和本地静态检查不直接办理入图或改变任务状态。

编号、Spec/Plan、准入、同步和维护规则由 RoadmapGuide 统一维护。本页只提供入口，不复制规则或索引具体草稿。
