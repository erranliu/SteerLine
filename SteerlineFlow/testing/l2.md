# L2：受控核心冒烟

每次代码修改后、提交 PR 前运行一个固定集 `smoke.delivery`，建议整体 5 分钟内。入口：`go run ./cmd/test-feedback -level=L2`；环境 controlled，仅需 Go、Git，无真实模型或 GitHub 副作用。

执行 [TestDeliverySmoke](../../tests/e2e/smoke/delivery_test.go)：使用真实 SteerLine/Git/SQLite 和公开 Runner/PR 夹具，贯通任务依赖、候选执行、PR 合并、唯一交付和后继释放；核对停止回执与资源清理。报告为 `full-L2`，只表示当前定义的完整受控冒烟；真实模型链见 [L4](l4.md)。

| ID | 验证与通过条件 |
| --- | --- |
| `smoke.delivery` | 创建依赖任务，执行至待合并后合并；唯一交付、后继 ready 未启动，重复读取无新执行，停止回执与清理完整。完整受控冒烟通过。 |

输出目录必须全新；结果、日志、清理和复验要求见 [报告约定](reports.md)。返回 [测试指南](../testing.md)。
