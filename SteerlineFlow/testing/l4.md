# L4：可复用测试与专项

按变更影响选择，包含边界测试、无法并行的功能、真实链及单元/集成测试集。以下 E2E 的实现映射见 [suites.json](../../tests/e2e/suites.json)，环境/完整命令/约束见 [JSON](test-list.json)。

```powershell
go run ./cmd/test-feedback -level=L4 -suite=<suite> -env=<controlled或live> -scenario=<ID或逗号分隔ID>
```

controlled 需要 Go/Git；项目维护和测试记录还需要 Windows、Node/npm、Edge，E2E 入口自建公开 Runner 夹具。live 必须单独精确选择，需要本机 Codex 和固定 Runner；交付/审计还需要 SteerlineTest GitHub 写权限，会创建并合并本次专属 PR。审计另设两个不同的 `STEERLINE_AUDIT_EXECUTION_MODEL` / `STEERLINE_AUDIT_MODEL`。测试管理真实链消耗模型、不发布 PR。

项目维护、测试记录、测试管理真实链共享源码 Web 依赖及构建目录，须串行，不能与其他 Web 安装/构建命令并发。四项 runtime 边界独享资源，可包内二并行；与项目维护同选时整个包串行。L4 包间串行，live 单项运行。

| ID | suite / 环境 | 主要断言 |
| --- | --- | --- |
| `runtime.dual-home-isolation` | runtime / controlled | 两 home 使用相同 task/request ID，discard 后原参数重放回执一致、版本不变；另一 home/provider 无改写、无候选，实例不变。 |
| `runtime.path-isolation` | runtime / controlled | 拒绝 state junction、越界 run_dir、退役 worktree_root 和 DB/WAL/SHM hardlink，受保护数据不变；普通文件恢复后正常可用。 |
| `runtime.project-maintenance` | runtime / controlled | 新独立调试包中真实 Go/Web/Edge 验证快进、三版自动材料、独立候选、过期测试禁用、旧PR交付与跨项目隔离；模拟 Runner，停止与清理完整。 |
| `runtime.service-write-isolation` | runtime / controlled | 陈旧实例、冻结目录外写入及同 repo 跨 home 启动均拒绝且零请求/候选副作用；正常控制通过，重启后仍拒绝旧实例。 |
| `runtime.source-build-isolation` | runtime / controlled | 拒绝源码 bin junction/EXE hardlink 指向隔离安装夹具；合法构建保持源码及受保护夹具的 EXE/数据库/任务事实不变。 |
| `smoke.local-codex` | smoke / live | 运行真实 Runner/Codex 实现、报告和发布，核对三个 final、真实产物及精确 merged PR、唯一交付和未启动后继，清理完整。 |
| `testing.management-local-codex` | testing / live | 真实自动生成保存系统安排，原干净 Run 实际执行先通过再失败的测试程序，经 Runner artifacts、Git、API 和浏览器核对原报告及绑定；停止和资源清理完整。 |
| `testing.records` | testing / controlled | 新隔离包中实际脚本失败与修正通过，按受测 SHA 导出 Git JSON；未合入不可见，主分支合入后 API/浏览器可读，重复导出不重复、失败保留、删文件清理，停止和资源结算完整。 |
| `workflow.local-codex-audited` | workflow / live | 使用两个显式模型完成实现、两轮审计、发布与真实 PR 合并；核对正式产品详情中的模型/材料/审计来源、唯一交付与后继 ready 未启动，清理完整。 |

## 可复用 Go 测试集

| ID | 入口与范围 | 通过条件 |
| --- | --- | --- |
| `go.full` | `go run ./cmd/test-feedback -level=L4 -suite=go`；isolated，复用 Full 三 worker，全部普通 Go 包的单元/集成/owner/边界回归，包含 L1。 | 包及用例枚举/终态完整，无遗漏或重复；必要断言通过。存在跳过时受管报告不计完整通过。 |

L1 仅选择其中最小规则和边界；L2/L3/L4 的 e2e 标签流程不在 Go Full 内。按 owner 定向执行可缩小诊断范围，但不输出 `go.full` 通过。

## 其他可复用入口

| 入口 | 内容与约束 |
| --- | --- |
| `scripts/test-web.ps1` | Web 构建、Vitest 与 HTTP owner；可选 DebugConfig 浏览器冒烟。共享源码 Web 构建目录，串行。 |
| `scripts/test-web-smoke.ps1`、`scripts/test-unified-startup.ps1` | 隔离调试包的浏览器交付、双项目流程，前置见 [调试指南](../../docs/runtime-install-debug.md)。 |
| `scripts/test-deployment-stop.ps1`、`scripts/test-web-switch-build.ps1` | 部署停止、Web 切换的脚本专项；使用各入口自有隔离夹具。 |
| `scripts/test-debug-release.ps1`、`scripts/test-execution-profile-discovery.ps1` | 新调试包的生成/冻结/停止/reset，以及真实执行目录发现；需要固定 Runner，使用共享源码构建目录，串行。 |

配置导航的独立 UI 专项使用 `npm --prefix web run test:e2e -- configuration-navigation.spec.ts`：构建后的客户端由临时本机 HTTP 服务器提供，API 全部受控拦截；检查两个配置入口、返回/后退、共享并发保存和宽窄屏布局，不代表真实服务或 Runner 验收。

这些独立入口尚未接入统一受管报告，不作为已登记 JSON 项；实际日志按 [报告约定](reports.md)保留。其断言不因未登记而删除，也不能推断已被 L1 或 Go Full 覆盖。

输出目录必须全新；结果、日志、清理和复验要求见 [报告约定](reports.md)。返回 [测试指南](../testing.md)。
