# 远端环境检测 checkout 准备

SteerLine 冻结检测所用的最新基线，先在远端已有 checkout 核验检测材料。材料一致时直接提交检测，HEAD 可以不同。材料不同时提交独立的 Runner 快进操作，再核验一次。只有复核通过才执行项目入口。快进目标保持为本次冻结的分支和提交。准备与检测共用请求指定的时限。

隔离服务测试覆盖材料一致、快进后复核通过和快进后仍有差异。L1、L2 原报告位于本次执行机的系统临时目录 `steerline-remote-ff-l1-cf43` 和 `steerline-remote-ff-l2-cf43`。配对 308 checkout 做了只读占用检查，真实快进和检测未运行。
