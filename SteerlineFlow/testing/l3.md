# L3：可并行功能测试

按变更影响选择。以下均为 controlled：真实 SteerLine/Git/SQLite，公开 Runner/PR fixture，无真实模型。每项独立 home、repo、数据库、端口、provider 和证据；只复用只读构建产物，清理归创建场景。

各 ID 的完整命令及约束见 [JSON](test-list.json)，对应 package/test 见 [执行登记](../../tests/e2e/suites.json)。

```powershell
go run ./cmd/test-feedback -level=L3 -suite=<suite> -env=controlled -scenario <ID或逗号分隔ID>
```

当前仅支持 Windows，需要 Go/Git。配置场景另需 Node/npm、Edge 和已构建 Web 资产：先串行 `npm --prefix web ci`、`npm --prefix web run build`；场景只读复用资产，不与源码 Web 构建并发。

可跨 suite 选择，包间最多二并行；仅 runtime 包内也最多二并行，跨包时包内串行。recovery/runtime 有既有并行记录；配置与材料生成的组合证据归[本次验收](acceptance/test-content-alignment.md)，只代表已执行组合，不宣称全部组合已验证。

| ID | suite | 主要断言及独有覆盖 |
| --- | --- | --- |
| `testing.project-environment-readiness` | testing | 两项目两环境经公开准备，仅对应组合可启动；失效阻断新工作且原候选可交付，完整停止清理；受控不等于原生通过。 |
| `testing.runtime-progress` | testing | 固定测试字段、通过/重跑清零、非法内容和断连保留快照、重启零业务输入、独立业务 revision、不生成 managed 历史及停止清理。 |
| `configuration.execution-profiles` | configuration | 浏览器条件保存本机Orca三Agent配置、待重启门槛、正式停启、关闭Web后CLI核对adapter/target/agent/model/effort/helper，原候选不变且资源清理完整。 |
| `recovery.waiting-merge-restart` | recovery | PR 待合并时重启 SteerLine，保持原候选/Run/请求，零自动新输入、不提前释放后继；合并后唯一交付，资源清理完整。 |
| `recovery.runner-wait-retry` | recovery | 公开准备查询等待/调用/退避/耗尽/清除、HTTP/活动与重启预算保持、零自动输入、原恢复/取消限制、终态停止及唯一交付；公开 Runner fixture；远端夹具先经公开适配命令与 closed 结果取得 ready，不跳过环境准入，不证明真实环境/PR或原生重试资格。 |
| `runtime.dual-home-operation` | runtime | 两独立 home 同时在线，以不同请求 discard 不同任务；另一项目/provider 不变、无候选，实例不变，两者停止清理完整。 |
| `runtime.service-lifecycle` | runtime | 中文与空格路径、无关 cwd 下创建启动器，核对任务、宿主身份和控制；停止结算，再启动新实例保持任务事实，最终清理完整。 |
| `runtime.async-activities` | runtime | 原检测/候选观察阶段保留零额外输入、320px/焦点、断连/刷新/原Run重启及交付清理；独立页/摘要深链接默认零交互正文查询，显式一页索引及单段正文或完整短预览免查询，轻量检查不追页、历史无焦点重取，1440/768/320px与请求计数证据由执行器校验。独立项目浏览器验证解析的真实来源变化拒绝、检查更新、首次/并行候选和环境检测发起，即时局部反馈、飞入及窄屏减少动态效果、每意图一次命令和两次候选提交。先构建Web资产；不新增生成/发布模拟引擎，现场独立，两项目正文合计10分钟/包12分钟，原独立清理保留。 |
| `runtime.shared-runner-projects` | runtime | 同 home 两项目分别经公开项目检测取得资格后共用一个 Runner，相同产品请求号创建独立 Run；分别消费仓库/PR，整体重启保持绑定、零自动新输入，全体资源清理完整。 |

输出目录必须全新；结果、日志、清理和复验要求见 [报告约定](reports.md)。返回 [测试指南](../testing.md)。
