# L1：最小代码检查

每次代码修改后、提交 PR 前运行一个固定集 `l1.minimum`，建议整体 1 分钟内。入口：`go run ./cmd/test-feedback -level=L1`；环境 isolated，仅需 Go、Git。

固定范围见 [scoped.go](../../cmd/test-feedback/scoped.go) 和 [task_scope.go](../../cmd/test-feedback/task_scope.go)：任务状态/契约/依赖规则、公开 Runner 契约、原子写入保留旧快照、Windows/Linux 公开依赖边界，以及清单/列表一致性。执行分组属于同一测试集，默认三个 worker；可用 `-workers=1` 诊断。

完整 owner 回归、启动/恢复/部署、HTTP/Web、SQLite 等专项保留在 L4 `go.full` 中；不为每项新功能扩张固定 L1。冷编译可能超出建议时间，报告须记录实际总耗时。

| ID | 验证与通过条件 |
| --- | --- |
| `l1.minimum` | 固定最小任务规则、公开契约、持久化与依赖边界、清单一致性全部执行，终态完整、断言通过、无意外跳过。 |

输出目录必须全新；结果、日志、清理和复验要求见 [报告约定](reports.md)。返回 [测试指南](../testing.md)。
