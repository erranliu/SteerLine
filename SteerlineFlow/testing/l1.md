# L1：最小代码检查

一批代码改动完成、交付候选稳定后运行一次固定集 `l1.minimum`；后续按影响补测或复用，具体时点与条件见[测试指南](../testing.md#日常执行)。建议整体 1 分钟内。入口：`go run ./cmd/test-feedback -level=L1`；环境 isolated，需要 Go/Git、Node 24+ 与已安装 Web 依赖。

固定 Go 范围见 [scoped.go](../../cmd/test-feedback/scoped.go) 与 [task_scope.go](../../cmd/test-feedback/task_scope.go)，所有分组明确选择测试根，不整包吸收新增回归：

| 范围 | 固定根 |
| --- | --- |
| 原子持久化 | `TestAtomicWriteENOSPCPreservesPreviousSnapshot` |
| 任务模型 | `TestContractDigestAndReferenceBoundary`、`TestBatchValidationAndReadinessShareTaskRules` |
| 任务重放、结果及依赖 | `TestTM03TaskBatch`、`TestTM03Result`、`TestTM03Dependencies` |
| Runner 调用方契约 | `TestTakeoverWireIdentity` |
| 测试清单 | `TestTMRegisteredCatalogueMatchesExecutableManifest`、`TestScenarioContentListMatchesRegisteredIDsAndLevels`、`TestRegisteredCommandsSelectExactlyTheirDefinitions` |
| 提示词正文、参数及材料 | `TestPromptGovernanceGolden`、`TestPromptGovernanceRejectsInvalidInputs`、`TestTestingContextOnlyBindsRuntimeFiles`、`TestDocumentDrivenRuleCopies` |
| 真实仓库源码及架构 | `TestPromptGovernanceSourceBoundary`、`TestThreeLayerRepositoryBoundary` |
| Runner 产品依赖闭包 | `TestRunnerExecutionBoundary` 及 Windows/Linux 两个子例 |

共 17 个 Go 根，包含各根全部子例。提示词源码守卫与架构根通过同一进程内缓存复用一次完整 Check，保留真实仓库 Windows/Linux、非活动源码及原依赖矩阵；开发者配置和原生配置源码所有权仍在完整 Check 内检查。Runner 边界保留独有的产品 CLI 闭包及退役目录断言，不重复扫描源码。提示词检查器人工正反例与原生配置反例全集归 L4 `go.boundary`。

前端固定范围见 [web.go](../../cmd/test-feedback/web.go)：`web/src/shared/api/client.minimum.test.ts` 的三个原用例验证等待期间冻结信封、POST 前持久化及未知操作只查询；`web/src/features/runs/state.minimum.test.ts` 的两个原用例验证候选状态及停止资格。完整请求故障/并发/锁/超时/回执恢复矩阵与其他状态映射保留在原测试文件，由 L4 `web.unit` 连同两个 minimum 文件一起执行；原断言只迁移、不复制或删除。

Go 分组默认三个 worker，可用 `-workers=1` 诊断。不构建 Web、不启动浏览器。先 `npm --prefix web ci`；依赖缺失明确失败，不自动联网安装或跳过 Web。CI 仍准备 Node/npm 后运行同一完整 L1。固定提示词正文、参数、材料校验与源码门禁保留。

完整规则回归用 L4 `go.rules`，完整边界检查器回归用 `go.boundary`；二者仍包含在 `go.full`。新增功能默认进入相应 L4 或定向测试，不扩张固定 L1；确需新增关键门禁时显式审阅选择、文档及影响。App 环境/部署/Roadmap 源清单漂移仍由原清单检查阻断。冷编译可能超出建议时间，报告须记录完整命令的实际总耗时。

| ID | 验证与通过条件 |
| --- | --- |
| `l1.minimum` | 固定 Go 根及其子例、两个前端 minimum 文件共五个用例全部非零执行，原生报告/终态完整、断言通过、无跳过；关键根缺失、额外 Go owner 根或任一组失败整体不通过。 |

输出目录必须全新；结果、日志、清理和复验要求见 [报告约定](reports.md)。返回 [测试指南](../testing.md)。
