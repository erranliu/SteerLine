## 可用执行界面

任务列表与所选候选详情展示待执行/执行中/待决策/待合并/已完成、丢弃/历史及真实失败/未知原因。支持方案选择、首候选/新增候选、放弃、Task 丢弃、派发控制、服务停止与已有环境核验动作；服务仍重检精确身份/版本/资格。原控制台日常操作须可在 UI 完成；源码调试、安装及原生认证等操作仍从所属入口办理。

近期活动显示有界摘要，完整最终回复与问题背景可读，缺口明确。不给完整过程 transcript、工具正文分页、轮次折叠和跨重启阅读偏好恢复重新立项。规划对话历史以后在 2.3 独立设计。

反馈支持文字、选项、选项加备注；显示原任务/候选/Decision，发送前保存原信封。双击、响应丢失、重开沿原请求核实，服务明确 command_not_found 才按共同规则补交；未知外部动作只对账。切目标保留原草稿，不自动采用新版本补投。

答案保存、平台接受、新轮次开始分别显示，不要求业务应用证明。环境/权限阻断显示真实原因和可用核验入口；用户处理后由服务核验，不提供通用“确认即放行”。自定义人工前置与交付后人工验收办理归 2.2，不在这里创建另一套事项状态机。

精确 PR 链接由用户合并，merged/TaskDelivery 与后继释放来自中心。UI 关闭不停止 worker；离线显示最后采样和禁用变更，不要求新增离线查询进程。原会话无法继续时展示原因与未发送输入，不自行创建替代 worker。保留真实资源定位和人工处置事实，不因任务终态显示已清理。
