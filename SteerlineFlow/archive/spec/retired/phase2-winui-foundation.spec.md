## 最小客户端

显式选择项目/配置并按 #45 发现服务；核验协议、项目和实例。显示连接/身份错误、当前项目和一份真实任务列表查询；切项目或重连时拒绝旧响应，离线不得据缓存发业务命令。不自建业务状态机，不访问 SQLite 或私有日志。

建立可被 #49/#50 复用的窄查询/命令客户端和连接组件；本任务不交付完整执行按钮。原生输入的提交意图可在本地最小展示，明确未发送业务命令；真实反馈由 #50 接入。不设计未来领域的通用导航注册器。

## 输入与生命周期

采用原生多行编辑，支持中文 IME、粘贴、选区、撤销、换行和清晰的显式提交按钮；组词中的 Enter 不能误提交。首版只固定显式提交和换行行为，不先做多套发送快捷键/偏好系统。输入目标切换不得把旧草稿当成新目标输入；按实际项目/目标保存必要未发送草稿，不预建规划 session 模型。

提供输入的可访问性标签及基本键盘可达性。最小窗口在常用缩放/窄尺寸下可操作；最终页面布局和阅读位置持久化由原型确认后决定。

UI 不启动或停止 Go 服务；关闭窗口只结束观察，不改变服务或 worker 身份。固定 .NET/Windows App SDK 依赖及实际验证的 Windows 系统版本，提供原生构建/运行说明；不承担正式升级、跨平台 UI 或业务窗口编排。
